# Swapping of Two Numbers in Java

## Description
This Java program swaps two numbers using a temporary variable. It takes two integers as input from the user and exchanges their values.

## Concepts Used
- Java Programming
- Variables and Data Types
- User Input using `Scanner`
- Temporary Variable
- Basic Operations

## Code Explanation
1. Read two numbers from the user.
2. Store the first number in a temporary variable.
3. Assign the second number to the first number.
4. Assign the temporary variable to the second number.
5. Display the swapped values.

## Sample Input
```text
Enter first number: 10
Enter second number: 20
```

## Sample Output
```text
After swapping:
First number: 20
Second number: 10
```

## How to Run
1. Install the Java JDK.
2. Save the program as `Swapping.java`.
3. Open a terminal in the project folder.
4. Compile the program:
   ```bash
   javac Swapping.java
   ```
5. Run the program:
   ```bash
   java Swapping
   ```
